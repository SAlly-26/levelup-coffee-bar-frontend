El diseño de la pauta es referencial. Se cubren las vistas y flujos con una identidad adaptada a Level Up. No se ha enviado información a GitHub ni a un servicio de pago. La pauta tiene un rótulo “editar usuario” dentro de categorías: se interpreta como edición de categoría según el módulo.
